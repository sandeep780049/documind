Your documents,

DocuMind is a production-style Retrieval-Augmented Generation backend. Upload PDF or TXT files, and it extracts, chunks, embeds and indexes them with pgvector — then answers questions strictly from the retrieved context, with page-level citations.

What it does

Real backend behaviour — no mock responses, no hardcoded answers.

🔐

JWT authentication

Argon2 password hashing, bearer tokens and per-user isolation on every document, chunk and conversation.

📄

Document pipeline

PyMuPDF extraction, text cleaning, word-boundary chunking with overlap, and processing status tracking.

🧠

Local embeddings

sentence-transformers all-MiniLM-L6-v2 by default, with OpenAI and fastembed providers a config change away.

🔎

pgvector search

Cosine-similarity ANN search over an ivfflat index, scoped to the requesting user in SQL.

💬

Grounded RAG

Ollama runs the LLM locally; answers cite document name, page and similarity, and refuse when context is missing.

🗂️

Conversation history

Every question and answer is persisted with its sources, paginated and scoped to the account.

Try it in a minute

The live deployment runs the OpenAI provider; locally DocuMind runs fully offline.

BASE=https://documind-api-2a1i.onrender.com

# 1. Create an account (returns a JWT)
curl -X POST $BASE/api/v1/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com","password":"StrongPass123"}'

# 2. Upload a document
curl -X POST $BASE/api/v1/documents/upload \
  -H "Authorization: Bearer $TOKEN" \
  -F 'file=@handbook.pdf'

# 3. Ask a question about it
curl -X POST $BASE/api/v1/chat/ask \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"question":"What is the remote work policy?"}'
The API is rate limited. Register once, reuse the token, and keep the demo questions focused on documents you upload yourself.
